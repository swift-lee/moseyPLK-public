## 发布集合与归档

公开文件扫描没有发现私钥/凭证格式、个人绝对路径、实际启动标识或 MAC 等设备标识。文件内容和来源另经人工审查；自动模式扫描不能替代来源判断。[第三方说明](../THIRD_PARTY_NOTICES.md) 记录保留源码的归属。

源码归档验证仅在主机临时目录进行，逐项核对归档名、文件字节与公开清单一致，不产生安装包或公开二进制交付物。最终目录另行通过严格文件集合检查、文档链接检查和 Git 空白检查。所有构建器共用同一源码归档函数。

GMS resolver compatibility ID 与整理前源码一致；UI 与 OTA schema 补充版权/来源注释，另规范上游 schema 的尾随空白和公共 shell 的末尾空行；消息与运行逻辑不变。版本继续为 0.6.7 / code 20。
