### 未验证范围

本轮没有构建可选 adaptive-test APK，没有重新运行全部七份真实 APK 的 DEX/resolver 矩阵，也没有安装或操作手机。GMS adaptive 使用主机 fake API，不能验证 ART、真实 ClassLoader、LSPosed、SELinux、开机或实际无线收发。所有 provenance 的 `device_tested=false` 保持不变。

服务安装器只支持 KernelSU。服务 ZIP 中的外部供体和 launcher 不适用本项目原创源码的 Apache-2.0 授权；仓库与本次 Release 保持现有 private 可见性。

集成期间客户端清单检查曾因审查清单尚未生成而报错；清单完成后复跑已通过。最初未跟随引用文件的 ShellCheck 出现跨文件变量告警，使用上述模块引用上下文后通过。没有据此改写活动服务逻辑。最终 Git 空白检查发现两处保留源码中的空白问题，规范后重新检查通过。

实际环境为 Python 3.14.4、OpenJDK 25.0.4.1、系统 C 编译器 15.2.0、ShellCheck 0.11.0；这是本次验证环境，不表示所有其他工具版本均已验证。

### 发布集合与归档

公开文件扫描没有发现私钥/凭证格式、个人绝对路径、实际启动标识或 MAC 等设备标识。文件内容和来源另经人工审查；自动模式扫描不能替代来源判断。[第三方说明](../THIRD_PARTY_NOTICES.md) 记录保留源码的归属。

源码归档验证仅在主机临时目录进行，逐项核对归档名、文件字节与公开清单一致，不产生安装包或公开二进制交付物。最终目录另行通过严格文件集合检查、文档链接检查和 Git 空白检查。所有构建器共用同一源码归档函数。

GMS resolver compatibility ID 与整理前源码一致；UI 与 OTA schema 补充版权/来源注释，另规范上游 schema 的尾随空白和公共 shell 的末尾空行；消息与运行逻辑不变。版本继续为 0.6.7 / code 20。

### 未验证与下一条件

本次未构建 APK/KSU ZIP，未运行 Gradle/Android 编译、真实 APK/DEX resolver 矩阵或完整第三方依赖检查。受限策略、生成兼容检查、供体、工具和原签名均需由使用者另行提供，才能进行对应本地构建与产物回归。

没有连接或修改手机，未验证 ART/LSPosed、实际 root/SELinux、挂载视图、界面触控、GMS 绑定、无线发现或文件收发。需要这些结论时，先由用户完成必要安装/操作，再按 [工作流程](workflow.md) 安排有界只读验证。构建 provenance 的 `device_tested=false` 不改为实机成功。
